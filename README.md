# えぃにめ一閃流奥義「一閃」 macOS 版

アニメのスクショを撮って Discord に投げる営みを保証する GUI ツールの **macOS 版**です。

**原作は [Nu-Pan/aynime_issen_style](https://github.com/Nu-Pan/aynime_issen_style)（Windows 専用）です。**
本リポジトリはその fork で、**原作に忠実に macOS へ移植したもの**です。

- **機能は原作と同じ**です。macOS 版独自の機能・改善・拡張は一切入れていません
- 挙動に迷う箇所は、すべて原作（Windows 版）のコードを正として実装しています
- 変更したのは「Windows でしか動かない部分を macOS で実現する」ためのコードだけです
  （画面キャプチャ、グローバルホットキー、クリップボード、フォント、保存先、動画エンコーダ、配布形式）
- Windows 側の挙動は変えていません。共通コードは両 OS で同じ結果になるようにしてあります

使い方は原作の [wiki](https://github.com/Nu-Pan/aynime_issen_style/wiki/User's-Manual) がそのまま当てはまります。

## インストール

はじめての方向けに、順番どおりにやれば動く形で書いています。
**ターミナルを使う手順が 1 つだけあります**が、コピー＆ペーストで大丈夫です。

### 用意するもの

- macOS 12.3 以降（Monterey 以降）
- Homebrew … 入っていない場合は [brew.sh](https://brew.sh) の手順どおりに入れてください

### 手順 1. 動画の書き出しに使う道具を入れる

ターミナル（アプリケーション > ユーティリティ > ターミナル）を開いて、次の 1 行を貼り付けて Enter。

```
brew install ffmpeg gifsicle
```

数分かかります。これは動画（GIF や mp4）を書き出すために使う道具です。
**入れないと動画の保存でエラーになります。** 静止画だけなら無くても動きます。

### 手順 2. アプリをダウンロードして置く

1. [Releases](https://github.com/chikuwav/aynime_issen_style_mac/releases) から zip をダウンロード
2. ダウンロードした zip をダブルクリックして展開
3. 出てきた `aynime_issen_style.app` を **アプリケーションフォルダにドラッグ**

### 手順 3. 初回起動（ひと手間かかります）

このアプリは Apple の公証（notarization）を受けていないため、**そのままダブルクリックしても開きません。**

> Apple は、"aynime_issen_style" に Mac に損害を与えたり、プライバシーを侵害する可能性のあるマルウェアが含まれていないことを検証できませんでした。

こう表示されますが、故障でもウイルスでもありません。**「Apple の審査を通していない」**と言っているだけです。
公証を受けるのは面倒な為、対応していません。

1. アプリをダブルクリックする（上の警告が出たら、そのまま閉じる）
2. **システム設定 > プライバシーとセキュリティ** を開く
3. 下のほうにスクロールすると **「"aynime_issen_style" はブロックされました」** という行があるので、その横の **「このまま開く」** を押す
4. もう一度確認されるので「開く」を押す

この操作が必要なのは **初回だけ**です。

> **macOS 15 Sequoia 以降の注意**
> - **「このまま開く」は、1 の警告が出てから 1 時間以内に押してください。**
>   時間が経つとこの行が消えます。消えていたら 1 からやり直せば また出てきます
> - 昔あった「アプリを右クリック（control＋クリック）して開く」という近道は、
>   macOS 15 で廃止されました。上の手順が唯一の方法です

### 手順 4. 画面を録画する許可を与える

アプリはウィンドウの中身を読み取るので、macOS に許可を求めます。

1. アプリを起動すると **「"aynime_issen_style" が画面を記録しようとしています」** と聞かれるので、**「システム設定を開く」** を押して許可する
2. **許可したら、アプリをいったん終了して、もう一度起動してください**

**2 番目がとても大事です。** macOS は許可の状態をアプリの起動時にしか読み直さないので、
再起動しないと「ウィンドウが 1 つも出てこない」という状態になります。

> **macOS 15 以降では、月に一度この許可の再確認を求められます。**
> これは macOS 側の仕様で、アプリ側では回避できません。同じように許可してください。

なお、**アプリを新しい版に入れ替えたときは、許可を与え直す必要はありません。**

### 動かないときは

| 症状 | 原因と対処 |
|---|---|
| 「構え」タブにウィンドウが 1 つも出てこない | 画面収録の許可が反映されていません。手順 4 のとおり、許可したうえで **アプリを再起動**してください |
| 動画の保存でエラーになる | 手順 1 の `brew install ffmpeg gifsicle` がまだです |
| 録画したら保存に失敗した | 録画中に対象のウィンドウをリサイズすると起きます。サイズを変えずに撮り直してください |
| アプリが開けない | 手順 3 をやり直してください |

## 使ううえで知っておくとよいこと

- **別のディスプレイでアニメを全画面にして、一閃流は手元のディスプレイに置く**のがおすすめの構成です（原作 wiki の推奨と同じ）。同じディスプレイで全画面にすると、一閃流を操作するために画面を切り替えた瞬間にキャプチャが止まります
- ホットキーは Ctrl＋Opt＋I（一閃 = 静止画） と Ctrl＋Opt＋K（キンキン = 動画）。control＋option です。command では無いので注意
- 有料配信サービスのプレイヤーは、保護のかかった部分が黒塗りになることがあります。これは原作（Windows 版）でも同じです
- 5 秒ぶんの映像を常に保持しているので、録画時のメモリ使用量は 3 GB 前後になります

### ファイルの保存先

| 用途 | 場所 |
|---|---|
| キャプチャ結果 | `~/Pictures/aynime_issen_style/{nime,raw,tensei}` |
| 設定 | `~/Library/Application Support/aynime_issen_style/` |
| ログ | `~/Library/Logs/aynime_issen_style/` |

## 原作との関係

- 本リポジトリは原作の fork です。**macOS で動かすために必要な差分だけ**を持ちます
- キャプチャ部分は、Windows 版の `aynime_capture`（C++ / Windows.Graphics.Capture）ではなく、
  ScreenCaptureKit で実装した [chikuwav/aynime_capture_mac](https://github.com/chikuwav/aynime_capture_mac) を使います
- **原作リポジトリへは変更を送りません。** このリポジトリのコードは AI が生成したもので、
  原作の開発規約が AI エージェントによるファイル編集を禁じているためです。
  原作に取り込んでほしい変更がある場合も、こちらから Pull Request を送ることはありません

## 今後の課題

- **Homebrew の cask で配る。** 個人 tap を用意すれば `brew install --cask` の 1 行で導入でき、
  Gatekeeper の警告も出ず、ffmpeg / gifsicle も同時に入る。費用ゼロで利用者体験が一番良くなる
- **Apple の公証（notarization）。** 起動時の警告を完全に消せるが、
  Apple Developer Program（年 $99）の契約が必要。問い合わせが増えてから検討する
- **ffmpeg 依存をなくす。** mp4 は `AVAssetWriter`（VideoToolbox）で直接書ける。
  外部ツールのインストールが不要になるが、GIF の出力は別途考える必要がある

## 開発者向け

### 環境

- Python 3.13（Tcl/Tk 8.6 系。CustomTkinter 5.2.2 が Tk 9 を想定していないため）
- ffmpeg / gifsicle（`brew install ffmpeg gifsicle`）

### セットアップ

```
python3.13 -m venv .venv
.venv/bin/pip install -e .
```

### 実行

リポジトリのルートで実行します（カレントディレクトリがルートである必要があります）。

```
PYTHONPATH=src .venv/bin/python src/gui/main.py
```

画面収録の許可は **起動元のアプリ**（ターミナルや VSCode）に紐づきます。許可を与えたら、そのアプリを再起動してください。

### 配布物のビルド

```
AIS_CODESIGN_IDENTITY="Competitive Screenshot Club" PATH=.venv/bin:$PATH PYTHONPATH=src .venv/bin/python -m build.main
```

`release/` に zip ができます。

`AIS_CODESIGN_IDENTITY` にはコード署名用の自己署名証明書の名前を渡します。
省略すると ad-hoc 署名になりますが、**ad-hoc 署名はビルドのたびに変わる**ため、
macOS が別のアプリとみなして画面収録の許可を求め直します。
利用者にとっては「更新のたびに許可し直し」になるので、配布用のビルドでは必ず指定してください。

証明書はキーチェーンアクセスの証明書アシスタントで作れます（自己署名ルート / コード署名 / 有効期間は長めに）。
**同じ証明書を使い続けることが重要**なので、作ったら書き出して保管しておいてください。
